# DYT 遥测接入需求

## 功能范围

1. 基于 PX4 v1.17.0，硬件目标为 `cuav_7-nano_default`。
2. 飞控只接收 DYT 遥测并发布 uORB，不向 DYT 发送任何数据。
3. TELEM2 固定为 DYT 接口，对应 `/dev/ttyS3`，TTL 电平转换已由硬件验证正常。
4. 实体串口输入和 SITL UDP 输入二选一，不要求同时接收。

## 实体串口

1. `serial_probe` 在 CUAV 7-Nano 开机时自动启动。
2. 串口使用 8N1、无流控，并以只读方式打开。
3. 参数 `DYT_BRAND` 只选择接收波特率：
   - `0`：`zhongkeyoucheng`，115200 baud；
   - `1`：`aisheng`，230400 baud。
4. 修改 `DYT_BRAND` 后，重启 `serial_probe` 使波特率生效。
5. 解析器按帧头识别厂家报文，不依赖 `DYT_BRAND` 判断报文类型。

## 中科友成遥测

1. 使用“周期性遥测信息”格式：帧头 `0xEE 0x16`，32 字节定长，小端。
2. 校验值为字节 0～30 累加和的低 8 位，存放于字节 31。
3. 合法报文发布到 `dyt_zhongke_telemetry`。

## 艾盛遥测

1. 协议以 `agent_zsh/aisheng-DYT-20260717.pdf` 为准。
2. 帧头为 `0x55 0xAA`，长度字节为 `0x68`，整帧 104 字节，小端。
3. 校验值为文档字节 4～103 累加和的低 8 位，存放于文档字节 104。
4. 合法报文发布到 `dyt_aisheng_telemetry`，`timestamp` 使用飞控启动后的微秒数。
5. `track_status` 取 `work_status` 的 bit0。
6. 文档字节 77～87 映射为 `status2`、`tracking_gate_w`、`tracking_gate_h`、
   `pitch_attitude`、`yaw_attitude`、`roll_attitude` 和 `tracking_target_type`；
   `tracking_gate_w`、`tracking_gate_h` 表示波门宽度和高度。

## SITL UDP

1. `dyt_udp_bridge` 只编译进 SITL，并由 02 场景为每个 PX4 实例启动。
2. instance 0 监听 UDP 9000，后续实例端口按 instance 序号递增。
3. 模块解析艾盛 JSON 字段并发布 `dyt_aisheng_telemetry`；样例中不存在的字段保持消息默认值。
4. `target_confidence` 写入 uORB 数组的第 0 个元素。
5. UDP 输入发布时，`self_check` 和 `work_status` 固定为 `0x01`。
6. UDP 输入发布时，`timestamp` 使用飞控启动后的微秒数。
7. JSON `tracking_gate_w`、`tracking_gate_h` 映射至同名 uORB `uint16` 字段，
   接受 0～65535 的有限数值，按四舍五入（0.5 进 1）转换为整数像素。
   两字段独立可选，缺省为 0；负数、越界或非数值字段拒绝整包。

## 验证要求

1. 串口报文需覆盖合法帧、分段、粘包、噪声、错误长度、错误校验和及错误后恢复。
2. 使用 `listener dyt_aisheng_telemetry` 或 `listener dyt_zhongke_telemetry` 检查数据与发布频率。
3. `serial_probe status` 应显示当前品牌、波特率、有效帧数和错误计数。
4. 若实体串口持续无数据，先检查并交换 DYT TX/RX 接线。
